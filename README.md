# Аудиокниги

Веб-приложение для прослушивания аудиокниг из нескольких источников с оплатой платных книг банковской картой.

## Запуск

Нужен Node.js 18+. Зависимостей нет.

```bash
node server.js
```

Откройте http://localhost:3000.

## Приложение для iOS

В папке `ios/` лежит проект Xcode. Приложение — оболочка над этим же интерфейсом: оно открывает сервер, держит звук в фоне и на заблокированном экране и хранит покупки и прогресс между запусками. Ключи провайдеров и платежей остаются на сервере.

Нужен Xcode 16 или новее.

1. Запустите сервер: `node server.js`.
2. Откройте `ios/Audiobooks.xcodeproj` в Xcode.
3. Выберите симулятор iPhone и нажмите Run.

В симуляторе приложение обращается к `http://localhost:3000` на вашем Mac. Адрес сервера меняется кнопкой ⚙ в шапке; значение по умолчанию задаётся в `ios/Audiobooks/ContentView.swift`.

Для запуска на телефоне:

- в настройках таргета (Signing & Capabilities) выберите свою команду и замените идентификатор `com.example.audiobooks`;
- разверните сервер по адресу с HTTPS и укажите его в приложении. Без HTTPS работает только локальная сеть.

Что стоит знать:

- У приложения нет иконки.
- Для публикации в App Store Apple в большинстве стран требует продавать цифровой контент через встроенные покупки (In-App Purchase), а не через Stripe.

## Провайдеры

Каждый источник книг — отдельный адаптер в `providers/` с двумя методами: `search(q)` и `getBook(id)`.

| Провайдер | Файл | Что это |
|---|---|---|
| LibriVox | `providers/librivox.js` | Бесплатные книги, настоящий API |
| Internet Archive | `providers/archive.js` | Бесплатные книги, настоящий API |
| ЛитРес | `providers/litres.js` | Платные аудиокниги, партнёрский API (нужны ключи) |
| Демо-магазин | `providers/demostore.js` | Пример платного каталога для проверки оплаты |

### ЛитРес

Работает через [API для интеграции партнёров](https://docs.litres.ru/public/205502033.html). В `.env` нужны `LITRES_PARTNER_ID` и `LITRES_SECRET_KEY`; без них провайдер скрыт.

- У API нет поиска, поэтому каталог выгружается в `data/litres-catalog.jsonl` (только аудиокниги) и обновляется раз в 6 часов. Первая выгрузка полного каталога может занять много времени; ЛитРес разрешает 10 выгрузок в сутки.
- Ссылки на аудио живут 5 минут, поэтому плеер получает звук через `/api/stream`: сервер проверяет покупку и проксирует файл.
- Цены приходят в рублях и пересчитываются в `LITRES_CURRENCY` по курсу ЦБ РФ или по `LITRES_RUB_RATE`.
- Сейчас в `.env` стоит тестовый доступ из документации ЛитРес — в нём несколько книг, из них одна аудиокнига.
- Продавать книги ЛитРес можно только по договору с ними. Отчёт о продажах в ЛитРес не реализован: его формат в новой документации не описан и согласуется при подключении.

Чтобы подключить своего поставщика, скопируйте `providers/_template.js`, реализуйте два метода и добавьте адаптер в `providers/index.js`. Ключи API кладутся в `.env` и остаются на сервере.

## Оплата

Используется Stripe Checkout: покупатель вводит карту на странице Stripe, номер карты через это приложение не проходит. Stripe принимает карты, выпущенные в разных странах, и сам проводит 3-D Secure.

1. Скопируйте `.env.example` в `.env`.
2. Впишите `STRIPE_SECRET_KEY` (`sk_test_...` для проверки, `sk_live_...` для настоящих платежей).
3. Укажите `BASE_URL` — публичный адрес приложения.

Без ключа работает демо-режим: вместо Stripe открывается страница-заглушка, деньги не списываются.

Цена берётся на сервере из каталога провайдера, а факт оплаты проверяется запросом к Stripe — ссылки на аудио платной книги отдаются только после этого.

## Что нужно доделать перед настоящим запуском

- Регистрация и вход: сейчас покупки привязаны к анонимной cookie браузера.
- База данных вместо `data/purchases.json`.
- Webhook Stripe `checkout.session.completed` — чтобы покупка засчитывалась, даже если покупатель закрыл вкладку до возврата на сайт.
- Защищённая выдача аудио (подписанные ссылки или прокси): в демо-магазине файлы лежат в открытом доступе.
- Stripe открывает счета не во всех странах; модуль `payments.js` изолирован, его можно заменить на другого платёжного провайдера.
